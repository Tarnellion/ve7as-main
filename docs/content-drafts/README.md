# Черновики контента

Это **сырьё, а не публикации**. Путь черновика в прод:

1. Владелец проходит по всем маркерам `[VERIFY: …]` / `INSIDER-VERIFY` и
   подтверждает или правит инсайдерские утверждения.
2. Владелец сверяет остальные факты с первоисточниками из текста.
3. Текст вставляется в Sanity Studio:
   - статьи — в `body_<lang>` соответствующего документа article;
   - хабы — в `body_<lang>` документа section (поле появилось в схеме,
     Studio нужно передеплоить: `cd studio && npm run deploy`).
4. Комментарии `<!-- OWNER NOTES … -->` и маркеры VERIFY перед вставкой удаляются.
5. Плейсхолдер `{{TOOL: wagering-calculator}}` в статье о вейджере заменяется
   обычной ссылкой на `/en/tools/wagering-calculator/` — или остаётся ссылкой
   в тексте: шаблон статьи уже сам рендерит плашку инструмента.

Деплой сайта после вставки НЕ нужен: контент читается из Sanity на каждый запрос.

# Автоматизация новостей: как устроено и что куда вносить

Воркфлоу: `.github/workflows/news-daily.yml`. Расписание — раз в сутки, 05:17 UTC;
запустить вручную можно в Actions → «Новости — ежедневный конвейер» → Run workflow.

## Цепочка

| Шаг | Скрипт | Что делает | Платно |
|---|---|---|---|
| 1 | `harvest.mjs` | собирает ленты за 7 суток, отсекает точные дубли | нет |
| 2 | `cluster.mjs` | склеивает по смыслу, считает независимые группы, сверяет с журналом | нет |
| 3a | `preflight.mjs` | токен Sanity, ключ Anthropic, режим и числовые ручки — **до** первого платного вызова | нет |
| 3b | `generate.mjs` | факты → черновик → критика → правка → перевод ES → мета → **второй проход по обоим языкам** | да |
| 4 | `deliver.mjs` | решает по `policy.mjs`, куда ложится материал, и пишет в Sanity | нет |
| 5 | `journal-record.mjs` | заносит **доставленное** в журнал; журнал коммитится в репозиторий | нет |

Журнал (`scripts/news/state/journal.json`, около 4 КБ) живёт в репозитории: у раннера нет
памяти между запусками, а путь закрыт `paths-ignore` в `deploy.yml`, так что коммит бота
не пересобирает сайт.

## Два режима

Переменная репозитория `NEWS_PUBLISH_MODE`:

- **`draft`** (по умолчанию, если переменной нет) — всё уходит в Studio черновиком, публикует человек.
- **`auto`** — материал, прошедший **все** гейты ниже, публикуется сам; остальное остаётся черновиком.

Гейты автопубликации (`scripts/news/policy.mjs`, каждый закрывается отдельным тестом в `selftest-policy.mjs`):

1. **подтверждение** — три независимых **голоса** (дословные перепечатки схлопываются в один) или первоисточник-регулятор; для обычной публикации хватает двух. Порог можно только **поднять** переменной, ниже трёх он не опускается: публичный текст обещает «не менее трёх»;
2. **источники реально прочитаны** — тексты скачаны у нужного числа групп (кластер говорит «подтверждено», а два из трёх изданий могли ответить 403); факты непусты и опираются на прочитанные группы; в тексте источника нет обращений к модели;
3. постпроверка кодом на обоих языках (штампы, ритм английского, объём, структура, **ссылки и картинки**, сверка **чисел** перевода с оригиналом) и **проверка меты** (`metaCheck`: заголовок и описание теми же СЛУЖЕБНЫМИ правилами, что текст (кириллица, пометки о подготовке, ссылки, HTML; штампы, ритм и объём к мете не применяются, и публичная редполитика обещает именно это), плюс запрет пометок о статусе нашей проверки — «not verified», «sin confirmar», «only in the headline», «we checked…», «verified by Ve7as»). Границы слов — через `\p{L}`, не `\b` (он не видит «ú»). Нарушителю даётся один повтор запроса меты с названием проблемы; если нарушение осталось, материал уходит черновиком с кодом `meta-check-en`/`-es`. Список шаблонов конечен: он ловит известные формулировки, а не любую; с «by …» («not confirmed by the operator») оговорка законна как атрибуция;
4. **второй проход модели по английскому и испанскому тексту, включая заголовки и описания** — без выдуманного, преувеличенного, арифметических ошибок и призывов играть;
5. не назван по имени частный человек в связи с обвинением, судом, санкцией, нарушением или смертью;
6. тема не из списка «только человек»: ключевые слова на пяти языках по оригиналу заголовка, фактам и итоговым текстам. Это **эвристика**, не гарантия, и публичный текст говорит именно так;
7. ни один ответ модели не оборван по `max_tokens`; мета полная; раздел из списка;
8. не дубль: событие, похожее на уже выбранное в этом прогоне или на журнальное, откладывается (кластеризация не склеивает кросс-языковые пары — нидерландский KSA и английские статьи о нём);
9. потолок **3 публикаций за прогон** — ограничивает цену ошибки, если какой-то гейт перестанет держать.

**Главное свойство режима draft:** `policy.mjs` считает «ушло бы в публикацию при auto» независимо
от режима и пишет это в заметки к каждому материалу (документ `newsReview` в Studio). Неделя
черновиков с такой пометкой показывает, совпадает ли ваше мнение с мнением гейтов, — до того,
как вы включите автопубликацию.

**Политика и публичный текст связаны.** Раздел «How AI is used» редполитики (ru/en/es)
перечисляет эти гейты читателю. Меняя порог или добавляя гейт, правьте и текст: обещание,
не совпадающее с поведением, хуже отсутствия обещания. Порог «три группы» — в обоих местах.

## Что внести и куда

### GitHub → Settings → Secrets and variables → Actions → **Secrets**

| Имя | Значение | Статус |
|---|---|---|
| `SANITY_PROJECT_ID`, `SANITY_DATASET` | уже заведены для деплоя | есть |
| `SANITY_WRITE_TOKEN` | Sanity → проект → API → Tokens → Add API token; имя `ve7as-news-bot`, роль **Editor** (не Administrator) | **завести** |
| `ANTHROPIC_API_KEY` | ключ API — **только если идёте по ключу** (см. ниже) | по выбору |

### …→ **Variables** (это идентификаторы и переключатели, не секреты)

| Имя | Значение | Зачем |
|---|---|---|
| `NEWS_PUBLISH_MODE` | не задавать (= `draft`) или `auto` | режим доставки |
| `NEWS_PER_RUN` | `2` (по умолчанию) | сколько событий за прогон |
| `NEWS_ENABLED` | `false` | **выключатель расписания**: ручной запуск продолжает работать |
| `NEWS_AUTO_MAX_PER_RUN` | `3` (по умолчанию) | потолок публикаций за прогон |
| `NEWS_AUTO_MIN_GROUPS` | `3` (по умолчанию) | порог независимых голосов для auto; **можно только поднять**, ниже трёх не опускается; менять вместе с текстом политики |
| `NEWS_RUN_BUDGET` | `4` (по умолчанию, $) | предохранитель: прогон остановится сам при превышении. Недопустимое значение («2,5») заменяется значением по умолчанию с предупреждением, а не отключает предохранитель |
| `NEWS_VERBOSE_LOG` | `1` | **только для отладки**: печатать в лог Actions причины целиком. Лог публичен, а в причинах бывают имена |
| `ANTHROPIC_FEDERATION_RULE_ID` `ANTHROPIC_ORGANIZATION_ID` `ANTHROPIC_SERVICE_ACCOUNT_ID` `ANTHROPIC_WORKSPACE_ID` | только при федерации | идентификаторы, не учётные данные |

## Ключ или федерация

**Начните с ключа, переходите на федерацию, когда конвейер отработает неделю.** Причина не
в том, что ключ лучше, а в том, что первые дни вы будете отлаживать сам конвейер, и сбой
доступа не должен быть среди подозреваемых. Код поддерживает оба способа и печатает в начале
прогона, каким воспользовался (`Доступ к API: …`).

**По ключу.** Создайте ключ в Console для CI **отдельно** от локального (он нужен в `.env`):
так их можно отзывать независимо. Лучше в отдельном рабочем пространстве `ve7as-news` с лимитом
расходов — лимит ставится на пространство, не на ключ. Положите в секрет `ANTHROPIC_API_KEY`.

**По федерации** (секрет не хранится вообще; токены живут минуты). Console →
`platform.claude.com/settings/workload-identity-federation` → **Connect workload** → плитка
**GitHub Actions**. Мастер создаёт три сущности и ждёт 15 минут первого обмена. Нужно:

1. Репозиторий `Tarnellion/ve7as-main`; префикс subject лучше сузить до ветки:
   `repo:Tarnellion/ve7as-main:ref:refs/heads/main` — расписание и ручной запуск идут с `main`.
2. Аудитория по умолчанию — `https://api.anthropic.com`. Если оставите пустой — тоже работает.
3. Scope `workspace:developer`; срок токена — любой от 600 до 3600 с (клиент берёт **свежий** JWT на
   каждый обмен, поэтому срок не критичен — см. комментарий в `scripts/news/client.mjs`).
4. Выписать идентификаторы мастера: `fdrl_…`, `svac_…`, ID организации — в **Variables**.
5. В окне мастера запустить воркфлоу вручную: подтверждение придёт, пока он слушает.
6. **Удалить секрет `ANTHROPIC_API_KEY`**: по документации Anthropic заданный ключ молча
   перекрывает федерацию. Клиент конвейера пустое значение за ключ не считает (проверено
   `selftest-client.mjs`), но пока секрет существует, он перекрывает федерацию. Проверка: в сводке
   прогона строка `доступ к API` должна сказать `федерация`, а в логе генерации — `федерация удостоверений`.
7. Если в журнале обменов Console видна причина `jti_reused` — токен кто-то использует повторно;
   клиент конвейера этого не делает (проверено `selftest-client.mjs`), ищите другой источник.

## Порядок включения

1. Завести `SANITY_WRITE_TOKEN` и способ доступа к API. Запустить воркфлоу вручную с `dry_run=true`
   (ни денег, ни записи) — проверяется только цепочка.
2. Запустить вручную без сухого прогона в режиме `draft`. В Studio появятся черновики с заметками.
3. **Неделя на `draft`.** Смотреть в заметках «ушло бы в публикацию при auto» и сверять со своим мнением.
4. Убедиться, что новая редполитика уже на проде (она едет тем же деплоем, что и пометка об ИИ).
5. Переменная `NEWS_PUBLISH_MODE=auto`.

## Как остановить и откатить

- **Остановить всё:** `NEWS_ENABLED=false`. Или режим `draft` — материалы продолжат приходить, но публиковать будет человек.
- **Снять выпущенное:** Studio → документ → Unpublish (текст вернётся в черновики). Страница исчезнет после истечения
  edge-кэша, до пяти минут.
- **Перепроверить прошлый прогон:** полные записи (источники, спорные утверждения, вердикты второго прохода, причины) —
  в закрытом документе `newsReview` в Studio. Артефакт прогона `news-report-<id>-<попытка>` (14 дней) содержит **только** публичный
  отчёт: идентификаторы, коды причин и стоимость — и нарочно не содержит черновиков.
- Тема, отданная черновиком и отклонённая вами, остаётся в журнале на 120 суток и больше не генерируется.
  Развитие того же сюжета с другим текстом склеится в новый кластер и пройдёт.

## Известные ограничения

- **Пометка у всех материалов конвейера — «без предварительной проверки» (`automated`), и у черновиков тоже.** Прочитав черновик, вы
  меняете её на «проверено редактором» (`assisted`) в Studio. Забытое значение правдиво и безвредно; забытое «проверено» было бы
  ложью на публичной странице.
- **Автор — «Ve7as».** Бот не подписывается именем человека: подпись реального человека под текстом, который он не
  писал и не читал, вводит читателя в заблуждение. Профилей авторов в Sanity нет вообще; при публикации черновика
  вы назначаете автора сами. В разметке `Article` автор идёт как `Person` с именем «Ve7as» — стоит заменить на
  `Organization`, это правка `src/lib/schema.ts`.
- Поля `*_ru` у новостей заполнены английским текстом: русский — корень фолбэка, без него три из пяти
  неиндексируемых локалей получили бы пустой заголовок. Индексу это не вредит.
- **Репозиторий публичен, значит публичны и логи Actions, и сводка, и артефакты.** В Actions скрипты печатают только коды причин,
  без имён и цитат; артефакт — только публичный отчёт; секреты заданы лишь тем шагам, которым нужны, а не всему заданию. Это не
  соображения вежливости: до ревью именно так утекали бы имена людей, которых проверка пометила как рискованных.
- **Если прогон оборвётся посреди работы, часть оплаченного пропадёт**: записи пишутся, когда событие прошло все фазы, а не после
  каждой. Предохранитель трат и доставка записей после сбоя (`!cancelled()`) смягчают это, но не снимают.
- **Расписание включается самим пушем.** Без секретов предполётная проверка остановит прогон до оплаты, но письмо о красном прогоне
  придёт; чтобы этого избежать, поставьте `NEWS_ENABLED=false` до первого ручного запуска.
- **Дата правки показывается под заголовком, когда прошли сутки с публикации** — это решение страницы статьи (правка опечатки через
  минуту после выпуска не должна светиться), и политика сформулирована именно так. Поле `dateModified` в разметке обновляется всегда.
- Cron в Actions не обещает точного времени; при нагрузке запуск запаздывает на десятки минут.
- Источники иногда отдают 403 (`igamingbusiness`, часть SBC) — для догрузки текстов это нормально, событие
  подтверждается остальными.
- **Датасет публичный, поэтому заметки редактора лежат не в статье.** Всё, что есть в опубликованном документе, читает
  любой через API. Заметки (критика, спорные утверждения, названные люди) пишутся в отдельный документ `newsReview`,
  который существует только как черновик (`drafts.` в идентификаторе): по документации Sanity черновики не отдаются
  анонимным запросам. **Не публикуйте `newsReview`** — тогда он станет публичным. После передеплоя Studio у этого типа нет кнопки
  Publish (`document.actions` в `studio/sanity.config.js`); это защита от случайного нажатия, а не сетевая защита.
- Поле `aiDisclosure` читается сайтом и без передеплоя Studio; но чтобы **увидеть** `newsReview` и редактировать
  `aiDisclosure`, Studio нужно передеплоить: `cd studio && npm run deploy`. Без передеплоя заметки всё равно лежат в Sanity (их видно во вкладке Vision запросом `*[_type=="newsReview"]`), но не в обычном списке.

## Темы, где без инструмента в выдачу не войти

Топ этих кластеров состоит из калькуляторов; текст без инструмента там не конкурент:

- **Wagering requirement calculator** (депозит+бонус, weighting, sticky/non-sticky) — комбинированного инструмента в найденной выдаче нет
- **Blackjack house edge calculator** по правилам стола — у конкурентов в этой выдаче инструмента нет
- **Odds converter** (american/decimal/fractional + implied probability) — обязателен
- **Vig / no-vig fair odds calculator**
- **Kelly criterion calculator** (с fractional)
- **Pot odds calculator** — единственный шанс в высококонкурентном кластере
- **Lottery odds calculator** (m из n) и **jackpot EV calculator** (split, налоги)
- **Slot session simulator** (волатильность/hit frequency наглядно) — ни у кого нет

Все инструменты — чистый клиентский JS: нулевой бюджет соблюдается, квота Sanity не тратится.

**Риск:** кластеры про бонусы граничат с коммерческой выдачей — держать строго объяснительный формат без списков казино.

# Семантика: исходные списки и подсказки Google

Здесь лежит сырьё для семантического ядра: списки запросов, подсказки Google
и частотность из Планировщика ключевых слов.

- `seeds-en.txt`, `seeds-es.txt` — исходные запросы (73 и 61): калькуляторы,
  кластеры из `../intent-map-2026-08.md`, испанские варианты для Испании и
  Латинской Америки. Подготовлены для Планировщика ключевых слов Google Ads.
- `suggest-2026-11-12.csv` — подсказки Google по каждому исходному запросу,
  2028 строк, 1030 уникальных формулировок. Колонки: язык, страна, страница
  сайта, исходный запрос, позиция подсказки, подсказка.

- `volumes-2026-11-12.csv` — частотность из Планировщика ключевых слов Google
  Ads, 156 запросов (81 английский, 75 испанских). Колонки: список, запрос,
  среднее число запросов в месяц, нижняя и верхняя граница, страница сайта.
  Снято 12.11.2026 за период ноябрь 2025 — октябрь 2026, все страны, все языки.

## Частотность: что это за цифры

- Это диапазоны (10–100, 100–1 тыс., 1–10 тыс. …), а не точные значения:
  аккаунту без запущенной рекламы Планировщик точных чисел не показывает.
- Регион — весь мир, язык не ограничен. Поэтому у международных слов из
  испанского списка (pot odds, provably fair, rtp slots, closing line value)
  цифра общемировая, а не испаноязычная.
- «нет данных» значит, что Планировщик не вернул по фразе ничего; обычно это
  очень низкий спрос.
- Цифра не различает смыслы. «calculadora de cuotas» (1–10 тыс.) — в основном
  про взносы и рассрочку: подсказки к ней — «de préstamo», «de hipoteca»,
  «de autónomos», «seguridad social», ставки там одна из десяти.
  «calculadora de bonos» — про облигации. Про ставки однозначны
  «calculadora de momios», «conversor de cuotas», «convertidor de momios».
  Перед выводом сверяйте запрос с его подсказками в `suggest-2026-11-12.csv`.
- Близкие варианты Планировщик склеивает: «wagering requirement calculator»
  и «wagering requirements calculator» вернулись одной строкой.

## Подсказки: как читать

Подсказка показывает, что такую фразу набирают, и как именно её формулируют.
Она не показывает, сколько раз. Пустой список подсказок — признак слабого
спроса на точную формулировку, но не доказательство нуля.

## Ограничения

- Запросы шли к `suggestqueries.google.com` 12.11.2026 с одного адреса.
- Разбивка по странам ненадёжна: списки для Испании и Мексики совпали во всех
  проверенных случаях, параметр страны на выдачу подсказок не повлиял.
- В подсказки попадает чужой смысл: «calculadora de margen» — это маржа в
  торговле, «qué es el rtp» в Мексике — транспортная сеть, английское
  «rollover calculator» — пенсионные счета. Такие строки из таблицы не убраны.
- Колонка «страница» проставлена по исходному запросу правилами, не вручную.

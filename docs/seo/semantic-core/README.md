# Семантика: исходные списки и подсказки Google

Здесь лежит сырьё для семантического ядра. Частотностей в нём нет.

- `seeds-en.txt`, `seeds-es.txt` — исходные запросы (73 и 61): калькуляторы,
  кластеры из `../intent-map-2026-08.md`, испанские варианты для Испании и
  Латинской Америки. Подготовлены для Планировщика ключевых слов Google Ads.
- `suggest-2026-11-12.csv` — подсказки Google по каждому исходному запросу,
  2028 строк, 1030 уникальных формулировок. Колонки: язык, страна, страница
  сайта, исходный запрос, позиция подсказки, подсказка.

## Как читать

Подсказка показывает, что такую фразу набирают, и как именно её формулируют.
Она не показывает, сколько раз. Пустой список подсказок — признак слабого
спроса на точную формулировку, но не доказательство нуля.

## Ограничения

- Запросы шли к `suggestqueries.google.com` 12.11.2026 с одного адреса.
- Разбивка по странам ненадёжна: списки для Испании и Мексики совпали во всех
  проверенных случаях, параметр страны на выдачу подсказок не повлиял.
- В подсказки попадает чужой смысл: «calculadora de margen» — это маржа в
  торговле, «qué es el rtp» в Мексике — транспортная сеть, английское
  «rollover calculator» — пенсионные счета. Такие строки из таблицы не убраны.
- Колонка «страница» проставлена по исходному запросу правилами, не вручную.

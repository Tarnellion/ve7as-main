# Секреты новостного конвейера

> **В этом файле нет и не может быть значений секретов.**
> Репозиторий `ve7as` **публичный**: всё, что сюда попало, считается
> опубликованным навсегда — удаление коммита не убирает его из форков,
> кэша GitHub и поисковых индексов. Здесь хранятся только **имена**
> секретов, их назначение, место заведения и **даты**.
>
> Значения живут в GitHub → *Settings → Secrets and variables → Actions* и
> в панелях соответствующих сервисов. Не вставляй их ни сюда, ни в
> `.claude/settings.local.json`, ни в текст задач или отчётов.
>
> Если секрет всё же оказался в коммите — он скомпрометирован. Порядок:
> сначала **отозвать** его в сервисе, затем выпустить новый, и только потом
> заниматься историей git.

## Статус

**Ни один секрет из таблицы ещё не заведён.** Конвейер не построен; таблица
описывает то, что понадобится, и служит чек-листом на момент запуска.
Колонка «Последняя ротация» заполняется в день фактического создания или
перевыпуска секрета.

## Правила обращения

- **Минимальные права.** Роль и скоуп указаны в колонке «Назначение» — при
  выпуске выбирать именно их, а не «полный доступ, потом сузим».
- **Один секрет — одна задача.** Токены на чтение и на запись не совмещаются,
  даже если сервис позволяет.
- **Ротация по календарю.** Дата в колонке «Последняя ротация» плюс срок жизни
  даёт дедлайн. Просроченный токен отзывать, а не продлевать.
- **Никаких секретов в логах.** GitHub маскирует только то, что пришло из
  `secrets.*`; значение, собранное в скрипте из кусков или полученное по сети,
  не маскируется. Не печатать ответы API целиком.
- **Локально** — только `.env` (в `.gitignore`). Не `.claude/settings.local.json`:
  Claude Code сохраняет одобренные команды дословно, вместе с подставленными
  значениями.
